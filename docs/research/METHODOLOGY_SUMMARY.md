# Implemented methods and pending evidence

RQ1 measures unique eligible feedback distributions with known-label and total-case
denominators, missingness and source/time coverage. Predictions, reviewed labels and
adjudicated gold remain separate. Complaint samples cannot represent all citizens.

Data acquisition requires actual scoped rights, protected receipt and privacy review.
Proposed taxonomy has eight topics plus separate sentiment/severity tasks. Annotation
supports independent submissions/adjudication, but none is claimed to have occurred.
Group/duplicate-aware frozen splits preserve the protected final test; missing severity
uses task-specific eligibility rather than invented labels.

RQ2 uses existing TF-IDF LR/LinearSVC and genuine PhoBERT infrastructure, with documented
Vietnamese normalization/segmentation and checkpoint provenance. Same dataset/taxonomy/
task samples, validation-only selection/calibration and unchanged STEP 11 locked final
evaluation are mandatory. A random tiny Transformer is only an engineering test.

RQ3 separates KPI numerical correctness, supported statistical alerts with reference
events, and standardized dashboard interpretation/usability tasks. Event dates use
Asia/Ho_Chi_Minh reporting windows with UTC storage and explicit missing dates.

RQ4 prespecifies deterministic difficulty-balanced AB/BA MANUAL_ONLY/AI_ASSISTED allocation,
no repeated case for a participant, separate experiment cases, actual consent and an
eligible evaluated assistance model. Participant/case-aware statistics, confidence
intervals, missingness, order effects and insufficient-evidence rules are implemented.
