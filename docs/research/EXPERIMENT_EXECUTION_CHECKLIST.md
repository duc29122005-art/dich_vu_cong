# Prospective genuine experiment checklist

- Obtain actual scoped source permission, receipt and privacy review; satisfy applicable
  institutional/provider requirements. Do not treat this checklist as approval.
- Record taxonomy human review; collect actual independent annotation/adjudication where
  the protocol requires it. One person's repeated labeling is not independent validation.
- Freeze verified gold and leakage-free groups/splits. Keep protected test labels inaccessible.
- Train genuine baselines and verify the real PhoBERT checkpoint/segmentation before
  fine-tuning. Fit calibration and review thresholds on the authorized validation split.
- Freeze STEP 11 selection/comparison protocol before separately authorized final testing.
- Define actual dashboard reference events/tasks; separate correctness from usability.
- Before recruitment: settle participant access/ethics requirements, materials, voluntary
  consent, pseudonymization/withdrawal and retention. No participant is currently invented.
- Freeze eligible AB/BA allocation before observations. Avoid repeated participant cases
  and training/tuning overlap; document assistance-model provenance.
- Record real session measurements, missing/abandoned cases and deviations without filling
  gaps with synthetic values. Keep identity/consent mapping outside Git.
- Run the prespecified clustered analysis only with sufficient support and independent
  gold; otherwise report INSUFFICIENT_EVIDENCE. Complete result templates from actual
  authorized manifests. Review findings and source references honestly.
- Execute retention/withdrawal/deletion policy including backups; record evidence privately.

Use RESEARCH_READINESS_MATRIX.md to track status, responsibility, dependencies and verification.
