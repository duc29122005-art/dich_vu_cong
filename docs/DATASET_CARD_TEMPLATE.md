# Dataset card template — incomplete research instrument

Do not fill this template with synthetic metrics and present it as a real corpus.
Generated synthetic cards are visibly marked SOFTWARE/SYNTHETIC. A real generated
card must be human-approved by its exact checksum before publication.

1. **Dataset name/version:** immutable identifier and schema version.
2. **Research objective:** supported Vietnamese public-service tasks.
3. **Source/provenance:** authorized source IDs, source versions and manifest hashes.
4. **Permission/usage scope:** current approval references, retention, expiry,
   redistribution conditions; keep sensitive evidence protected.
5. **Construction methodology:** inclusion/exclusion rules, preprocessing version,
   known duplicate grouping, actual coverage and missing annotations.
6. **Annotation methodology:** independent annotators, handbook, adjudication,
   unknown severity/task eligibility, excluded outcomes and human approval reference.
7. **Taxonomy:** exact version, checksum and stable label mappings.
8. **Agreement reference:** independent task reports and their denominators; no
   scientific validity claim from high Kappa alone.
9. **Record count:** actual source, annotated, included, excluded and unannotated counts.
10. **Class distributions:** each task and partition, including zero/minority classes.
11. **Splits:** actual counts/ratios, seed, method, group constraints and deviations.
12. **Time/agency/domain coverage:** verified event-date coverage/range, missing
    metadata, aggregate non-identifying buckets where needed.
13. **Missingness:** actual missing/ambiguous values and task masks.
14. **Duplicates/leakage:** known links, detection method, failures, uncertain candidates,
    review outcomes and limitations.
15. **Privacy:** human clearance and automatic screening limitations; never insert raw examples.
16. **Bias/representativeness:** source, selection and annotation limitations.
17. **Known limitations:** class imbalance, domain shift, temporal overlap, unknown severity.
18. **Permitted/prohibited uses:** exact source terms, no re-identification,
    no test-based model selection; release needs separate authorization.
19. **Reproducibility:** construction/configuration hashes, environment, file hashes,
    gold revision references, build timestamp and change policy.

The generated aggregate card is a review artifact. Private manifests retain detailed
evidence/retention references. External release requires a human-readable review of
the source's actual terms; the generic card statement does not replace them.
